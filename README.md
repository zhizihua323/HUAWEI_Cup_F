本仓库保存“华为杯”第二十三届中国研究生数学建模竞赛 F 题的题目资料、数据、分析代码、实验记录、论文材料和最终提交附件。

| 路径 | 内容 |
|---|---|
| `00_PROJECT_BRIEF.md` | 项目目标、研究范围和总体说明 |
| `01_PROJECT_STATUS.md` | 当前项目状态与完成情况 |
| `02_DECISIONS.md` | 关键决策、方法选择和裁决记录 |

| `提交附件汇总_V4_20260926_2030/` | 当前版本的论文提交附件、核验结果和复现材料 |

## 目录说明

### `F题/`

F 题的原始资料、数据附件、数据字典、处理后的数据以及与各子问题相关的分析材料。`real_attachments/` 中包含主要实验数据；其中部分大型数据文件使用 Git LFS 管理。

### `solution/`

模型分析、计算脚本、配置文件、测试代码、实验输出和质量评估结果。该目录是复现实验和查看模型结果的主要位置。

### `paper/`

论文写作与交付材料，包括论文正文、提纲、图表、参考文献、展示材料、Word/PDF 生成与质量检查文件。

### `提交附件汇总_V4_20260926_2030/`

面向提交的 V4 版本材料，包括论文 QA、各问题的正式运行证据、结果清单、数据/环境复现说明和最终附件汇总。

### `audit/`

项目总体审计、论文完整性检查、引用检查、结果来源核对和提交准备报告。

### `diagnostics/`

各任务和实验阶段的诊断结果、稳定性检查、敏感性分析、审计表和运行日志。

### `evidence/`

支撑论文结论和模型判断的证据、核验记录与中间材料。

### `tasks/`

按任务拆分的工作说明、执行要求、问题记录和交接文档。

### `recovery/`

项目恢复、故障排查和历史状态整理记录。

### `参考资料/`

竞赛、建模方法、数据来源和论文写作相关的参考资料。

### `tmp/`

临时脚本、预检结果和过程性文件。该目录主要用于工作过程，不建议将其中内容作为最终交付材料直接引用。

## 根目录附件

根目录中的竞赛公告、题目/论文模板、格式规范、操作手册和 AI 工具使用规定，是提交论文时需要遵循的官方或项目参考文件。

## 复现建议

1. 先阅读 `00_PROJECT_BRIEF.md`、`01_PROJECT_STATUS.md` 和 `03_DATA_CATALOG.md`。
2. 再查看 `solution/README.md` 及 `提交附件汇总_V4_20260926_2030/07_环境与复现/README_REPRODUCE.md`。
3. 根据需要进入 `solution/` 运行分析或测试脚本。
4. 最终论文和提交前核验材料优先查看 `paper/` 与 `提交附件汇总_V4_20260926_2030/`。

## Git 与大文件

本仓库使用 `main` 分支。较大的 `.parquet` 和 `.jsonl.xz` 文件通过 Git LFS 存储；本地临时依赖缓存和部分 LibreOffice 临时配置目录已通过 `.gitignore` 排除。
