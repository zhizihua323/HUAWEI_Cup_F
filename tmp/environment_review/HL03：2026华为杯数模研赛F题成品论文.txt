题 目： 算力约束下提升大语言模型能力的资源配置建模
摘要:
大语言模型能力提升不仅依赖参数规模与训练数据量，还受到数据质量、领域配比
及算力预算的共同影响。本文围绕“数据质量评价—广义标度律构建—多维资源优化—
能力前沿预测”建立一体化建模框架，系统分析参数量 ? 、数据量 ? 、数据质量 ? 与领
域配比 ?对模型损失及综合能力的影响。
针对问题一，对 22 个质量指标进行统一预处理，通过均值聚合、指标同向化和经
验分布函数（ECDF）变换消除数据形态、量纲及重尾影响，并利用熵权法构建综合质
量得分 ? 。全量处理 A1–A3 数据后，书籍与网页类语料质量较高，代码域较低；抽样
集与扩展集检验表明质量评价具有较好稳定性。进一步基于强负相关指标对识别质量冲
突，总体冲突率为 2.6%，书籍域和论文域较高，主要源于“长文档效应”。领域配比方面，
采用 clr 变换处理单纯形约束，二次型配比模型训练 ? 2 = 0.609，并在 1M、60M、1B
尺度上表现出较好的跨尺度稳定性。
针对问题二，在经典标度律中引入质量折算因子，以 ? ⋅ ? ?表示有效数据量，并通
过来源固定效应联合拟合真实训练轨迹与半合成质量实验。模型参数估计为 ? = 1.608、
? = 0.073、? = 0.308、? = 0.265、? = 0.894，真实源与半合成源的决定系数分别为 0.
993 和 0.940。结果表明，质量 ? 提高 0.1 所带来的损失改善约等价于参数规模扩大 14.
2%或训练数据量扩大 17.7%，且百亿参数以上继续扩大规模的边际收益明显减弱。
针对问题三，将基础训练、质量提升和长上下文注意力开销统一纳入算力约束。由
于成本函数不含领域配比 ?，联合优化可分解为配比优化与 ? − ? − ? 优化两个子问题。
最优配比可带来 Δ? = 0.526 的损失改善。在 1019、1022、1024 FLOPs 三档预算下，最
优质量分别为 0.495、0.904 和 1.000，并在 log ? ≈ 21.0 附近出现资源配置的结构性转移。
敏感性分析表明，长上下文会显著挤压规模预算，并推动资源向更高质量数据配置转移。
针对问题四，基于 424 个开源模型建立面板回归，分离规模扩张与非规模技术进步
的贡献。结果表明，参数规模效应显著，但样本期能力增长主要由架构、训练方法、数
据工程和后训练等非规模因素驱动。进一步构建 Loss–Benchmark 桥接模型，并融合机
制路径与时序外推路径，在算力年化增长放缓至 1.5 倍的情景下，预测未来 12 个月和 2
4 个月的开源能力前沿分别为 49.1 和 51.9。逐任务分析显示，MATH 任务前沿增长快于
综合能力，表明不同能力维度的技术演进并不同步。
综上，本文构建了“质量评价—配比建模—标度律统一—资源寻优—能力预测”的闭
环模型，将数据质量与领域结构纳入可计算的资源配置体系，可为大语言模型训练中的
规模、数据、质量与配比决策提供定量依据。

一、问题重述
1.1 研究背景与问题定位
大语言模型训练的本质，是在有限计算资源下通过参数、数据与训练策略的协同配
置，尽可能降低验证损失并提升下游能力。早期标度律研究主要回答“模型做多大、数
据喂多少”这一规模问题，而本题进一步把数据质量、领域结构、上下文长度和能力演
进同时纳入，使问题从单纯的经验拟合转化为带有明显决策属性的资源配置问题。
从工程角度看，参数量增加会提高模型表达能力，但也会同步增加训练与推理成本；
数据量增加可以缓解过拟合并扩大知识覆盖，却受到高质量语料稀缺的限制；质量提升
能够提高单位 token 的有效信息密度，但数据清洗、筛选和高质量数据获取同样消耗资
源；领域配比则决定有限训练 token 在不同知识域之间如何分配，其本质是一种结构性
资源配置。因此，N、D、Q 与 p 不能被孤立讨论。
另一方面，大模型训练中的资源约束并非只有基础训练计算量。随着上下文长度增
长，注意力计算的附加成本快速上升；当上下文接近数万 token 时，该项成本已可能与
基础训练成本同量级。由此，所谓“算力最优”不再等价于简单扩大 N 或 D，而需要同时
考虑规模、数据质量、数据结构与长上下文的竞争关系。
基于上述认识，本文把四个问题组织为一条连续的数据—模型—决策链：先从原始
质量指标中构造可比较的 Q 和配比效应 φ(p)，再将二者嵌入广义标度律，随后在算力预
算下求最优资源配置，最后利用 Loss–Benchmark 桥接把损失改善映射为能力提升，并
完成未来前沿预测。这样可以避免四问各自独立建模造成的参数口径不一致。
1.2 四个问题之间的逻辑关系
问题一是全篇的数据基础，其核心输出不是单一排名，而是两个可被后续模型直接
调用的量：综合质量评分 Q 与配比修正函数 φ(p)。Q 需要具有跨样本、跨领域和跨扩展
集的可比性；φ(p) 则需要能够描述同一训练规模下不同领域配比对损失的相对影响。
问题二承担统一建模任务。经典标度律只含 N 与 D，不能直接吸收问题一的质量与
配比信息。本文因此将质量解释为有效数据量的折算因子，并将配比作为相对于参考配
比的加性损失修正，使四个变量在同一损失口径下被统一。
问题三从“解释规律”转向“优化决策”。一旦问题二给出了 L(N,D,Q,p)，就可以将其
作为优化目标，再把基础训练、质量提升和长上下文成本写入预算约束。问题三的重点
不是选择某一种优化算法，而是先识别优化问题的结构，再选择稳定的数值求解方法。
问题四完成从损失到能力的最后一层映射。由于实际关心的是 Benchmark 能力而非
交叉熵损失，因此需要结合开源模型面板数据分离规模与技术进步，并利用桥接数据建
立 Loss–Benchmark 关系。这样，问题三的资源配置结果才能被转换为未来能力前沿。
近年来，大语言模型的参数规模、数据规模与训练算力快速增长，经典标度律能够
较好地刻画模型损失随 N 和 D 的变化规律[1-2]。然而，随着高质量语料逐渐稀缺，单
纯依靠扩大参数量或增加 token 数获得能力提升的成本不断上升。已有研究表明，数据
质量与领域构成同样会显著影响模型训练效果[3,5]，因此仅以“规模”解释能力增长已经
不足以支撑实际资源配置。
从训练决策角度看，参数量 N、数据量 D、质量水平 Q 与领域配比 p 并不是彼此独
立的因素。扩大 N、增加 D、提升 Q 以及延长上下文长度都会消耗算力；领域配比本身
虽然不改变总 token 数，却会改变算力在不同知识域上的利用效率。题目给出了质量数
据、配比实验、标度律数据以及开源模型能力数据，要求在同一框架下建立从“数据—
损失—算力—能力”的定量联系，并据此给出资源优化与未来能力预测。

问题一：数据质量评价与领域配比建模。需要对多种异构质量指标进行统一处理，
构建可解释的综合质量分 Q；当指标对同一文本给出相互矛盾的判断时，还需识别冲突、
分析成因并提出消解方法。在此基础上，根据多组领域配比实验建立 p 与交叉熵损失之
间的定量关系，并检验其跨模型尺度的稳定性。
问题二：跨维度数据融合与广义标度律。需要综合附件 A 与附件 B 的信息，将参
数量、数据量、数据质量和领域配比统一写入标度律，同时给出跨来源数据能够联合建
模的可检验依据。在模型建立后，还需研究各因素的边际效应、弹性以及质量和规模之
间的替代关系。
问题三：算力约束下的多维资源联合优化。总算力由基础训练、质量提升和长文本
注意力三部分开销组成，需要在不同预算下求解最优 N、D、Q 与 p，并分析预算跨越
多个数量级时资源投入结构是否发生质变；同时讨论成本函数形式、上下文长度与参数
不确定性对最优解的影响。
问题四：技术演进分解与能力前沿预测。需要结合开源模型历史数据，区分能力增
长中由规模扩张带来的部分与由算法、架构、数据工程和后训练等非规模因素带来的部
分；再建立验证损失与 Benchmark 能力之间的桥接关系，在算力增速放缓的情景下预测
未来 12 个月与 24 个月的开源模型能力前沿，并对预测不确定性进行量化。
二、问题分析
2.1 总体技术路线
本文遵循“先清洗口径、再建立规律、随后优化、最后外推”的思路。首先处理附件
A 中质量与配比数据，得到 Q 和 φ(p)；其次利用附件 B 中真实训练轨迹与半合成实验
联合标定广义标度律；再次将该标度律与成本函数组合，形成受约束优化；最后使用附
件 C 中的开源模型历史数据完成能力分解和未来预测。
在数据处理层面，始终坚持“训练口径与检验口径分离”。例如，ECDF 映射只由 A1
估计并外推到 A2、A3；配比模型只在训练配方上拟合，而跨尺度数据主要承担检验作
用；标度律中真实源与半合成源等权，避免样本量较大的数据源主导估计；预测环节中
对高可比和低可比桥接样本采用分层权重。
在模型选择层面，优先考虑可解释、可退化、可检验三个原则。可解释要求每个新
增变量都对应清晰含义；可退化要求广义模型在特殊条件下回到经典模型；可检验要求
关键假设都能通过独立数据或稳健性分析进行验证。
2.2 关键难点与解决思路
第一个难点是质量指标异构。若直接进行标准化与加权，不同量纲、不同方向和重
尾异常值会严重影响综合评分。因此采用“列表聚合—方向统一—ECDF 百分位变换—客
观赋权”的顺序，使所有指标最终被映射到统一的 [0,1] 质量语义。
第二个难点是领域配比具有闭合约束。17 个比例之和恒为 1，使原始比例之间天然
共线。本文使用成分数据分析中的 clr 变换，并采用配方间差分相关而非跨尺度绝对损
失 R² 作为检验指标，从而使评价对象与模型真正承担的功能一致。
第三个难点是跨来源标度数据的不可比性。真实轨迹与半合成实验虽然都观察 Loss，
但覆盖范围和基线不同。若分别拟合，不可约损失 E 容易出现病态值。本文通过共享幂
指数、允许来源固定偏移来联合拟合，并以各来源独立 R² 检验统一性假设。
第四个难点是优化变量跨越多个数量级。N、D 直接在原尺度上求解时，梯度和约
束容易失衡。本文对 N、D 取对数，并使用多起点 SLSQP；同时利用 p 不进入成本函数
这一结构，将四维问题分解为两个低维子问题。

第五个难点是能力预测的口径混杂。不同年份、不同验证集和不同模型类型之间的
能力数据并非完全可比。本文采用面板回归控制类型与后训练因素，并通过桥接加权、
bootstrap 与多路径融合避免对单一外推趋势的过度依赖。
针对问题 1，首先需要解决质量指标量纲、方向和数据形态不一致的问题。列表型
指标无法直接与标量指标比较，负向指标又与正向指标方向相反，而 dsir 类指标具有明
显重尾分布。为避免极端值主导归一化结果，本文以 A1 的经验分布为基准进行 ECDF
百分位映射，再通过客观赋权方法形成综合质量分。其次，质量冲突不能依靠主观固定
阈值判断，而应由指标相关结构与样本分布共同确定。最后，领域配比属于成分数据，
其分量总和恒为 1，直接回归会产生共线性，因此需先进行对数比变换，并通过配方间
损失差分而非绝对损失检验跨尺度稳定性。
针对问题 2，核心困难在于真实训练轨迹与半合成质量实验的覆盖区间和水平并不
完全一致。若分别拟合，半合成数据容易因损失区间过窄而产生不可约损失的病态估计。
因此，本文让幂指数在不同来源间共享，用固定效应吸收来源水平差，并通过各来源拟
合优度检验“形状一致、水平可偏移”的假设。数据质量则以有效数据量折算因子 Q^γ 进
入模型，使 Q=1 时自然退化为经典标度律，同时保留清晰的经济含义。
针对问题 3，首先分析成本函数的结构。训练开销和注意力开销均与 ND 成正比，
质量提升成本与 D 相关，而领域配比 p 不进入预算约束，因此联合优化可以分解为两个
独立子问题。对 N 和 D 而言，其数量级跨度很大，直接在原始变量上求解容易造成数值
病态，故采用对数变量并在多个初值下搜索。为了识别资源投入策略随预算变化的“结
构性转移”，本文跟踪各成本项占比相对于 logC 的变化，并用分段线性残差扫描定位斜
率断点。
针对问题 4，首先要避免“只看前沿模型”造成的样本选择偏差，因此采用全量开源
模型面板回归，并控制模型类型与后训练因素。其次，验证损失与综合 Benchmark 并非
同一量纲，必须利用同时具备两类观测的桥接样本建立映射。考虑到桥接数据可比性有
限，本文对不同样本分层加权，并用 bootstrap 传播参数不确定性。最终采用机制路径、
月度时序路径和年度历史路径相互校验，再在对数空间按逆方差加权合成，从而避免依
赖单一路径外推。
由此，全文形成“质量评价与配比规律提取 → 广义标度律统一 → 算力约束优化 →
技术演进与能力预测”的递进关系：前一问为后一问提供可直接复用的参数或函数，使
四个问题构成完整的数据与模型闭环。

三、模型假设
在正式建模前，除列出假设本身外，还需要说明这些假设为何在当前数据条件下可
以接受。本文的八条假设主要服务于“统一口径”和“降低不可辨识性”，并非意味着真实
训练过程完全满足这些简化条件。
对于列表型指标等权聚合，附件没有提供各分块的可靠监督权重，若额外人为设置
权重会引入新的主观性。算术均值是最保守的文档级聚合方式，并且后续还有熵权法在
指标层面重新分配权重，因此不会重复放大某一分块。
对于 A1 作为 ECDF 基准，ECDF 的目的不是估计总体概率密度，而是建立稳定的
相对秩尺度。只要 A1 对主要领域的分布具有代表性，就可以作为统一映射基准；A2、
A3 与 A1 的 KS/t 检验结果进一步支撑该使用方式。
对于配比效应可加，问题一的配比模型主要刻画同一尺度下配方之间的损失差异，
而问题二的标度律刻画 N、D、Q 引起的整体损失水平。将二者写成“基线损失+配比修
正”可以避免重复解释同一变化。跨尺度差分相关保持为正，说明加性修正在现有尺度
范围内具有经验依据。
对于预算约束取紧，在可行域内，增大 N、D 或 Q 在模型中均不会提高损失，因此
若最优解仍有剩余预算，就可以继续沿某个有利方向投入，使损失进一步下降。故在不
存在离散约束的连续优化近似下，最优点满足预算约束取等号。
对于综合能力使用六项 Benchmark 平均，单项任务容易受到任务难度和测评噪声影
响，简单平均能够提供一个透明、可复现的总体能力口径。本文同时保留 C8 的逐任务
分析，以避免综合均分掩盖任务间异质性。
1、假设 8 个列表型质量指标内部各分块的重要性相同，因此采用算术均值将其压
缩为文档级标量。该处理保留原指标的整体水平，同时避免人为引入额外权重。
2、假设 A1 抽样集能够代表质量指标的基准分布。所有 ECDF 映射均由 A1 估计，
并原样应用于 A2、A3，使抽样集与扩展集处于同一可比尺度。
3、假设领域配比对损失的影响可写成相对于参考配比的加性修正项 φ(p)，并且其
相对效应在不同模型尺度下近似稳定。该假设由 1M、60M 和 1B 三个检验尺度的配方

4、假设模型损失满足幂律衰减关系，数据质量通过 Q^γ 折算有效数据量。于是 Q=
1 时自动回到经典 N-D 标度律，可避免为退化条件额外增加约束。
5、假设真实训练数据与半合成质量数据具有相同的标度律形状，来源差异主要表

6、假设基础训练、质量处理与长上下文注意力开销可以相加，且三部分均基于同

7、假设开源模型的综合能力可由 6 个 Benchmark 的简单平均近似表征；模型类型、

5.1 数据质量评价模型
5.1.1 指标体系的统计特征与预处理原则
22 个质量指标并非同质变量。部分指标来自文本统计，反映重复、长度、字符结构
等表面属性；部分指标来自语义或教育价值模型，反映流畅度、可读性、推理性与教育
性；dsir 类指标则是相对检索或分布匹配信号。若直接把这些指标视为同一量纲，会使
数值范围较大的指标在加权前就获得不合理影响。
预处理的基本原则是只改变可比性，不改变原始排序信息。对于列表型指标，先在
文档内部聚合；对于方向相反的指标，只做单调反向；对于重尾指标，采用 ECDF 秩映
射而不是依赖极值的线性缩放。这样处理后，各指标都被转化为“越大越好”的相对质量
分位。
ECDF 的另一个优势是具有天然的稳健性。设某指标存在极少量异常极值，Min-Ma
x 会通过分母中的极差把绝大多数正常样本压缩到狭窄区域，而 ECDF 只使用排序，不
会改变中间样本之间的相对位置。因此，本题中 dsir 的大幅负值不会主导后续综合评分。
5.1.2 熵权法的选择依据
综合质量评分需要解决“不同指标应占多大权重”的问题。若采用专家赋权，需要额
外引入主观判断；若采用等权，又无法体现不同指标的信息量差异。熵权法通过指标分
布的离散程度衡量有效信息量，能够在没有额外标签的条件下给出客观权重，符合本题
数据驱动的要求。
从统计解释看，当某指标在所有文本上都接近同一水平时，其区分能力弱，信息熵
接近 1，权重趋近于 0；相反，当某指标在样本间差异明显时，信息熵下降，权重提高。
因此，熵权法的本质不是判断某个指标“理论上更重要”，而是判断它在当前样本中“提
供了多少可区分信息”。
为避免单一赋权方法决定最终结论，本文又使用 CRITIC 方法进行稳健性对照。两
种方法的样本级相关为 0.564，但域级排序一致，说明微观样本的相对位置存在方法敏
感性，而宏观领域结论较稳定。论文因此不把 Q 解释为绝对真值，而把它视为统一数据
尺度下的综合质量代理变量。
5.1.3 域级聚合与代表性检验
样本级 Q 适合描述单篇文本，而后续资源配置更关心不同语料域的整体质量，因此
需要进行域级聚合。本文采用域内均值作为中心位置，并用 95% 置信区间描述样本不
确定性。该处理可以把数十万条文本质量信号压缩为可直接与领域配比结合的域级参数。

附件 A1 的 22 个质量指标由 14 个标量指标和 8 个列表型指标组成。列表型指标本

其内部元素取均值。设第 j 个列表型指标含 K_j 个分量，则文档级值为：
xⱼ = (1/Kⱼ)·Σ xⱼₖ （1）
随后统一指标方向。广告含量、非字母词比例、大小写比例、top-2/3gram 重复率和
数字字符比例等 6 个指标属于负向指标，均转换为“值越大质量越高”。考虑到 dsir 类分
数存在 −1000 至 −2000 的重尾极端值，若采用 Min-Max 归一化会把大部分样本压缩到
很窄区间，因此以 A1 的经验分布函数作为基准，将任意观测映射到 [0,1]：
x′ⱼ = F̂ ⱼ(xⱼ) （2）
其中 F_hat_j 仅由 A1 估计，A2、A3 直接沿用该映射；扩展集超出 A1 取值范围时
截断到边界。对于负向指标，再令 x′_j←1−x′_j。该方法只依赖样本排序，对重尾和极
端值更稳健。
（2）综合质量评分
在统一尺度后，采用熵权法计算指标权重。将第 j 个指标划分为 10 个区间，记第 b
个区间的样本比例为 p_b，则信息熵越小，说明该指标区分样本的能力越强，其权重越
大：
eⱼ = −Σ p_b ln p_b / ln10， wⱼ = (1−eⱼ)/Σ(1−eₖ)， Q = Σ wⱼx′ⱼ （3）
计算得到权重最高的三个指标分别为句末标点比例 0.628、top-3gram 重复率 0.311
和数字字符比例 0.042。作为稳健性对照，进一步使用 CRITIC 法重新赋权，两种方法
得到的样本级 Q 相关系数为 0.564，域级排序保持一致，说明总体结论对赋权方法较稳
定，但个体文本排序仍存在一定敏感性。

5.2 质量冲突识别与消解
5.2.1 为什么必须显式处理质量冲突
综合评分会把多个指标压缩成一个数，但压缩过程可能掩盖指标之间的矛盾。例如，
长篇论文在内容完整性上可能得分较高，却因为篇幅、重复模式或检索归一化机制在形
态指标上得分偏低。若不识别此类矛盾，综合评分可能把“指标偏差”误认为“文本质量
差”。
因此，本文先从相关结构中筛选强负相关指标对，再用数据自身的 99% 分位差异
确定异常冲突，而不是人为设置固定 z 分差。该设计具有两个优点：一是不同指标对可
拥有不同阈值；二是阈值由数据分布决定，减少主观性。
总体冲突率只有 2.6%，但按领域分层后出现极强异质性，这说明冲突不是随机噪
声，而是具有结构来源。图 2 的主要价值也在于揭示这种域间差异，从而把后续分析从
“统计异常”推进到“机制解释”。
5.2.2 长文档效应的机制解释
书籍和论文的高冲突率与文本长度高度一致。dsir 类分数与词数、句数呈强负相关，
意味着其数值不仅受内容匹配影响，还受篇幅或归一化机制影响；部分语义模型对超长
文本的分块聚合也会产生系统性下降。由此形成一种典型现象：同一篇长文档在内容指
标上表现良好，在形态或检索指标上却被持续压低。
这种现象不能简单通过删除某类指标解决，因为形态指标在网页清洗、重复检测和
低质量文本识别中仍然有效。因此本文采用“冲突时降权、按域解释”的软处理，而不是
全局剔除。这样既保留指标信息，又减少领域偏差。
扩展集验证进一步说明该现象具有稳定性：arxiv 和 github 的冲突率与 A1 同域结果
接近。也就是说，长文档效应并非某个抽样批次的偶然结果，而是评价体系与文本形态
交互产生的结构性现象。

5.3 领域配比模型
5.3.1 成分数据建模的必要性
领域配比与一般回归变量最大的区别，是 17 个分量受到总和为 1 的闭合约束。任
意一个领域比例上升，都必然意味着至少一个其他领域比例下降，因此原始比例之间的
相关性部分来自数学约束，而不一定代表真实替代关系。
clr 变换将比例转化为相对于几何均值的对数比，使模型研究的对象从“绝对百分比”
转为“某领域相对其他领域的富集程度”。这种表示更符合配比问题的本质，也能够缓解
闭合约束造成的伪相关。

5.3.2 从线性模型到二次交互模型
线性模型只能描述“某一领域相对增加时损失如何单调变化”，无法刻画领域之间的
互补或替代。例如代码与数学数据同时增加可能产生不同于两者独立效应之和的结果，
因此本文进一步加入二次项和交互项。
线性模型 R² 为 0.254，加入质量项后提高到 0.361，说明领域质量能够解释部分配
方差异；二次模型进一步提高到 0.609，说明非线性与交互效应不可忽略。这里的提升
并不意味着二次模型可以任意外推，而是说明在训练支持范围内，它更能描述配方之间
的相对损失结构。
为防止高维二次模型在优化阶段给出训练范围外的极端解，问题三中对配比引入训
练支撑软约束和熵正则。也就是说，问题一负责拟合配比效应，问题三再通过可行域设
计控制外推风险，两部分在方法上形成闭环。
5.3.3 跨尺度检验指标的选择
不同模型规模下的绝对 Loss 水平差异主要由 N 与 D 决定，而配比模型只需要解释
同一规模下不同配方之间的相对优劣。因此，若直接用 1M 训练的模型去预测 60M 或 1
B 的绝对 Loss，评价会把“尺度差异”误算成“配比误差”。
本文改用配方差分相关：对同一尺度内的两种配方 i、j，比较模型预测的 Δφ_ij 与
实测 ΔL_ij。只要两者正相关，就说明模型能够正确判断“哪种配方更优以及差多少”。
这种检验更符合配比模型的功能。
图 3 同时给出三个尺度的验证结果，其目的不是追求所有点都落在 45° 线上，而是观察配方排
序与相对差异能否跨尺度保持。三个尺度均维持正相关，从而支持在后续广义标度律中把 φ(p) 作为
近似尺度不变的加性修正。
5.4 问题一的稳健性检验与结果讨论
问题一的结果将直接进入后续标度律与优化模型，因此不仅需要得到 Q 和 φ(p)，还
要检验结论是否过度依赖某一种预处理、赋权或回归形式。本文从质量赋权、扩展集代
表性、冲突规则和配比模型四个方面进行稳健性讨论。
首先，在质量赋权方面，熵权法与 CRITIC 法对样本级 Q 的相关系数为 0.564，说
明两种客观赋权方法在个体文本上并不完全一致。但域级排序保持稳定，意味着后续资
源配置所依赖的领域平均质量并未因赋权方法发生根本变化。因此，本题更适合在域级
使用 Q，而不是把单篇文本的排序解释为绝对质量真值。
其次，A2 与 A3 的扩展检验具有两重作用。一方面，它们检验 A1 的抽样是否能够
代表 arxiv 与 github 两个重要领域；另一方面，它们检验由 A1 估计的 ECDF 映射应用
到新数据时是否产生明显分布漂移。KS 与 t 检验均未发现显著差异，为跨数据集使用
统一质量尺度提供了经验支撑。
再次，冲突定义采用 99% 分位阈值而不是固定标准差阈值，这使每个指标对都可
以根据自身差异分布确定异常边界。若阈值过低，会把正常指标差异误判为冲突；若阈
值过高，又会遗漏真正的结构异常。99% 分位在本题中承担的是“只识别极端不一致样
本”的保守筛选角色。

提高至 0.361，再提高至 0.609，说明质量与非线性交互依次提供了额外解释力。但考虑
到二次模型参数更多，本文没有仅凭训练 R² 选择模型，而是进一步使用 1M、60M、1B

5.5 问题一小结
问题一最终完成了从原始异构指标到可用于优化决策的两个变量转换。第一，通过

六、问题二建模与求解
6.1 广义标度律的构建
6.1.1 质量进入标度律的两种思路比较
数据质量可以有多种进入标度律的方式。一种思路是让 Q 改变数据幂指数 β，使高
质量数据的边际收益曲线形状发生变化；另一种思路是把 Q 折算为有效数据量，使质量
影响数据项的“等效规模”。
本文选择第二种方式，主要基于三个考虑。第一，Q=1 时自动退化为经典标度律，
不需要额外约束；第二，γ 的含义清晰，可解释为质量对有效 token 数的弹性；第三，B
6、B7 的 N-D-Q 网格能够直接识别质量折算强度，而若让 Q 同时改变指数，需要更多
交互覆盖才能稳定估计。
有效数据量思想还有一个实际优势：它可以把“多买数据”和“买更好的数据”放到同
一尺度比较。若 Q 提升使 D_eff 增长，就可以直接计算与增加 D 或扩大 N 等价的资源
替代关系。
6.1.2 配比修正项的基准化
配比项采用 φ(p)-φ(p_ref) 而不是直接加入 φ(p)，是为了避免改变基础标度律的整体
水平。p_ref 取训练集平均配比，在该点修正项为 0，因此 L0 仍然代表“参考领域结构”
下的规模—质量关系。
这种基准化也使配比收益具有明确解释：若某配比的 φ(p) 低于 φ(p_ref)，则它相对
于平均训练配方降低损失；反之则提高损失。问题三中的 ΔL=0.526 正是在这一统一口
径下计算，因而可以与 N、D、Q 调整带来的损失改善直接比较。
经典标度律通常将交叉熵损失写成参数项和数据项的幂律叠加[1-2]。为了同时纳入
数据质量，本文不让 Q 直接改变幂指数，而是将其折算进有效数据量 D_eff=D·Q^γ。这
样既保留经典形式，又使 γ 具有“质量对有效数据量的放大弹性”这一明确含义：
L₀(N,D,Q)=E+A·N^(−α)+B·(D·Q^γ)^(−β) （7）
当 Q=1 时，上式自然退化为经典 N-D 标度律。问题一得到的配比函数则以相对于
参考配比 p_ref 的修正项进入总损失：
L(N,D,Q,p)=L₀(N,D,Q)+[φ(p)−φ(p_ref)] （8）
其中 p_ref 取 A4 训练集平均配比。训练配方中 φ(p) 的取值范围为 4.749–5.850，标
准差为 0.195，同一 N、D、Q 下最优与最差配方可产生约 1.10 的损失差，因此领域结
构不能简单视为次要扰动。

6.2.1 参数可辨识性与联合拟合策略

在来源间共享；而不同数据生成过程可能造成整体 Loss 水平偏移，因此允许固定效应 δ。

6.3 弹性与质量—规模替代关系
6.3.1 弹性的经济解释
弹性衡量某一因素按比例变化时，Loss 的相对变化。由于 ε_N 与 ε_Q 均为负，说
明增大参数和提高质量都会降低损失；绝对值越大，表示在参考点附近该因素的边际作
用越强。
在 N=1B、D=100B、Q=0.5 的参考点，参数弹性绝对值略高于质量弹性，但两者处
于同一数量级。更重要的是，随着 N 增大，参数项持续衰减，ε_N 的绝对值会进一步减
小，而质量仍可以通过有效数据量影响数据项，因此质量的相对价值会上升。
这种弹性分析把标度律从“预测曲线”转化为“决策指标”。资源配置者不需要只比较
最终 Loss，也可以通过局部弹性判断当前阶段更适合追加参数、追加 token，还是提升
数据质量。
6.3.2 等效替代量的推导意义
令质量提高 0.1 与参数扩大 k 倍产生相同 Loss 改善，本质上是在同一等损失曲线上
求两种资源的替代关系。求得 k=1.142，意味着在该参考点附近，质量从 0.5 提高到 0.6
的收益约相当于参数增加 14.2%。
同理，质量提高 0.1 约等价于训练数据量增加 17.7%。这两个比例不能脱离参考点
被理解为全局常数，因为标度律是非线性的；随着 N、D、Q 改变，替代率也会变化。
论文因此将其明确描述为“参考点附近”的局部结论。
这一结果对问题三具有直接价值：若质量提升的实际成本低于增加 14.2% 参数或增
加 17.7% 数据的等效成本，则优先提升质量更有利；反之则应继续投资规模。
6.4 广义标度律的模型比较与进一步解释
为了说明本文广义标度律的必要性，可以从三个层次比较模型。第一层是经典 N-D
标度律，只解释参数与数据规模；第二层加入 Q，把数据质量折算为有效数据量；第三
层再加入 φ(p)，形成 N-D-Q-p 完整模型。三个层次对应从“规模”到“质量”再到“结构”的
逐步扩展。
若令 γ=0，相当于取消质量折算，全样本 R² 从 0.973 下降到 0.945。虽然下降幅度
并非极端巨大，但考虑到质量实验本身覆盖区间较窄，仍说明 Q 提供了独立解释力。更
重要的是，γ 的加入使问题三能够计算质量与规模之间的替代关系，这是经典模型无法
完成的。
配比项的作用则主要体现在同一 N、D、Q 下的结构差异。训练配方中 φ(p) 范围约
为 4.749–5.850，说明相同规模和质量条件下，领域结构仍可能产生明显损失差。因此，
把 p 忽略为随机扰动会损失重要的决策信息。
从参数符号看，α、β、γ 均为正，因此 N 增大、D 增大、Q 提高都会使对应幂律项
下降，方向与理论预期一致。δ 为正且仅 0.073，说明半合成质量实验的整体 Loss 水平
略高于真实轨迹基准，但差异相对于总体 Loss 水平并不大，这也支持共享曲线形状的
设定。
模型的不可约损失 E=1.608 可以理解为当前函数形式下，当 N 与有效数据量趋于极
大时 Loss 的理论下界。它不是任何具体模型一定能够达到的真实物理常数，而是标度
律对现有数据区间的渐近估计。百亿参数模型距离 E 已较近，只能说明在当前幂律模型
中规模项边际作用正在衰减。
6.4.1 边际效应的解析形式

除弹性外，还可以直接从模型求偏导理解边际效应。参数项对 N 的边际变化与 N^
{-(α+1)} 成比例，因此 N 越大，单位新增参数带来的 Loss 改善越小；数据项对 D 的边
际变化与 D^{-(β+1)} 成比例，同样表现出递减收益。
质量 Q 通过 Q^{-βγ} 进入数据项，因此其边际作用不仅取决于 Q 本身，也取决于
D 与 β、γ。当 Q 较低时，提高质量可显著放大有效数据量；当 Q 接近 1 时，继续提升
的空间自然缩小。这一性质与问题三中 Q* 最终触及上界一致。
领域配比的边际效应由 φ(p) 的梯度决定。由于采用二次交互模型，其梯度会随当前
配比位置变化，因此同一领域增加 1 个百分点，在不同配方背景下可能产生不同结果。
这就是领域之间替代与互补能够被模型表达的原因。
6.4.2 从标度律到资源决策的转换
标度律本身只是描述损失如何随资源变化。要用于决策，还需要把“收益”与“成本”
放在同一框架中。问题二的弹性与等效替代分析完成了第一步：把质量改善换算成参数
或数据扩张的等价收益；问题三进一步把三类资源成本写入预算，完成真正的成本—收
益比较。
因此，问题二与问题三的关系可以概括为：问题二回答“投入某种资源能带来多少
损失改善”，问题三回答“在给定成本后，哪种资源最值得投入”。二者共同构成资源配
置模型的理论核心。
6.5 问题二小结
问题二通过有效数据量 D·Q^γ 和配比修正 φ(p) 将四个核心因素统一到同一 Loss 函
数中，并利用固定效应解决真实轨迹与半合成质量实验的水平差异。多层验证表明模型
在来源内、模型族间和百亿参数外推讨论中具有较好的结构一致性。
弹性与等效替代分析进一步把统计拟合转化为决策语言：在参考点附近，质量提高
0.1 的收益约等价于参数扩大 14.2% 或数据量扩大 17.7%。这为问题三构建成本约束下
的联合优化提供了直接依据。
取 N=1B、D=100B tokens、Q=0.5 为参考点，模型损失 L=2.454。参数规模与数据
质量的局部弹性分别为：
ε_N=∂lnL/∂lnN=−0.055， ε_Q=∂lnL/∂lnQ=−0.040 （11）
两者均为负，说明增加参数或提升质量都能降低损失，且在该参考点二者量级相近。
进一步令提升质量 0.1 与扩大参数后得到相同损失改善，即求解：
L(kN₀,D₀,Q₀)=L(N₀,D₀,Q₀+0.1) （12）
得到 k=1.142，即 Q 提高 0.1 的效果约等价于参数量扩大 14.2%；同理约等价于训
练数据量扩大 17.7%。这一结果给出了“买更高质量数据”与“买更多算力”之间可直接比
较的替代尺度。随着 N 增大并逐渐接近不可约损失 E，参数项的边际收益进一步下降，
因此高质量数据的重要性会相对上升。
七、问题三建模与求解
7.0 优化问题的构造原则

分为训练、质量与注意力三类。

在连续优化近似下，N、D、Q 被视为可连续调整的资源变量。实际工程中的模型
规模和 token 数是离散的，但在跨数量级的资源规划阶段，连续近似可以获得策略方向
与临界点；最终工程实现再对连续解进行离散化即可。
领域配比 p 的优化需要特别控制外推。二次型模型在训练分布外可能产生不合理的
极端预测，因此加入训练支撑软约束和熵正则，使最优配方保持在已有实验附近，同时
避免过度集中到少数领域。
7.1 算力成本模型与联合优化
7.1.1 三类成本的统一口径
基础训练成本 6ND 体现参数与 token 的乘积关系；质量成本 D·[g(Q)-g(Q0)]_+ 表示
质量提升必须作用于训练数据，因此与 D 成正比；注意力成本 ηNDL_ctx 则同时受到模
型规模、数据量和上下文长度影响。
三项成本使用同一 FLOPs 量纲后，才能在一个预算约束内比较。这里并不要求三
类成本完全来自同一硬件实现，而是将题目给定的相对开销统一折算成计算预算，从而
研究最优资源结构。
质量成本采用正部函数，是因为当 Q 不高于基准质量 Q0 时，不额外收取“质量提
升”成本。这保证低预算阶段可以选择停留在基准质量，而不会因为模型形式被迫为更
低质量支付负成本。
7.1.2 可分离性的数学解释
总目标可写为 L0(N,D,Q)+φ(p)-φ(p_ref)，约束 C(N,D,Q)≤C̄ 。由于约束完全不含 p，
p 的选择不会改变 N、D、Q 的可行域。因此，对任意可行的 N、D、Q，都可以先独立
选择使 φ(p) 最小的 p；反过来，p 的最优值也不依赖预算。
这意味着四维优化可以严格分解为两个子问题，而不是近似分解。其一是在训练支
撑范围内最小化 φ(p)，其二是在预算约束下最小化 L0(N,D,Q)。配比收益因此在不同预
算下保持固定，而 N、D、Q 的最优结构随预算变化。
这种结构性发现具有一般意义：只要某个决策变量进入目标函数但不进入预算约束，
它就可以被独立优化。问题三后续的数值计算因此主要集中在 N-D-Q 三维子问题。
7.1.3 数值求解稳定性
N 与 D 的数量级跨度极大，直接优化会出现数值尺度失衡。例如 N 的微小相对变
化在原尺度上可能是数亿，而 Q 只在 0 到 1 之间变化。将 N、D 取对数后，变量都转化
为相对尺度，梯度和步长更容易被优化器稳定处理。
SLSQP 适合处理连续变量、等式或不等式约束，并可直接使用边界。本文同时设置
Chinchilla 比例初值和多个随机起点，以降低非凸目标陷入局部最优的风险。若多个初
值最终收敛到相近目标值，可作为数值稳定性的辅助证据。
配比子问题在 clr 空间求解，可以自然满足成分数据的几何结构；再通过逆变换恢
复各领域比例。最终只接受满足训练支撑与熵约束的可行解，避免二次模型在边界外产
生不现实配方。
总算力由基础训练、质量提升和长上下文注意力三部分构成。设基准质量为 Q_0=0.
495，则总成本写为：
C(N,D,Q)=6ND+D·[g(Q)−g(Q₀)]₊+ηNDL_ctx （13）
其中第一项采用 Chinchilla 近似；第二项刻画从基准质量向更高质量提升所需的清
洗、筛选或获取成本；第三项为长上下文引入的附加注意力开销，η=2×10^−4。根据题
目给出的成本形式，分别考虑指数型、幂函数型和对数渐进型 g(Q)。

（1）优化问题的可分离性
结合问题二的广义标度律，资源配置问题可写为：
min L₀(N,D,Q)+φ(p)−φ(p_ref)， s.t. C(N,D,Q)≤C̄ （14）
由于 C 中不含 p，故最优配比与算力预算相互独立：原问题等价于在预算约束下最
小化 L_base，以及单独最小化 φ(p)。这一结构意味着“调领域配比”本身不增加总 FLOPs，
其收益在不同预算下保持不变。为避免配比优化进入训练分布之外，本文在 p 子问题中
加入训练支撑软约束和熵正则。
（2）数值求解
N、D 的取值跨越多个数量级，直接在原尺度求解会导致约束和梯度严重失衡。令
x=(lnN,lnD,Q)，并利用最优解处预算取紧的性质，将约束改写为对数等式：
min lnL(e^{x₁},e^{x₂},x₃)， s.t. lnC(e^{x₁},e^{x₂},x₃)−lnC̄=0 （15）
边界取 N∈[10^3,10^13]、D∈[10^6,10^16]、Q∈[Q_0,1]。采用 Chinchilla 比例构造解
析初值，并叠加多个随机起点使用 SLSQP 求解；配比子问题在 clr 空间使用 L-BFGS-B
搜索，最终取所有可行解中损失最小者。
7.2 优化结果与结构性转移
7.2.1 最优配比收益的解释
最优配比带来的 ΔL=0.526 远大于三档预算间 N、D、Q 调整产生的约 0.002 损失差，
这一结果首先说明当前数据下领域结构具有很高杠杆效应。但需要注意，该结论建立在
题目给定的配比实验与训练支撑范围内，不应直接外推为任何大模型都能通过配比获得
同等幅度收益。
图 6 采用最优配比与训练均值配比并列展示，是为了让读者直观看到资源从哪些领域迁移。其
目的不是强调某个具体领域一定应该提高或降低，而是说明最优配比并非简单的均匀扰动，而是结
构性重分配。
在实际应用中，配比优化可被理解为低成本的“第一优先级”决策：在总 token 数与
模型规模不变时，先优化数据结构；完成结构调整后，再决定是否追加参数、数据量或
质量成本。
7.2.2 三档预算与阶段性策略
三档预算的意义不是只给出三个离散最优点，而是代表低、中、高三个资源阶段。
低预算下，质量提升的固定或凸增成本占比较高，因此 Q 停留在基准值；中等预算下，
基础训练规模已经达到一定水平，继续只堆 N、D 的边际收益下降，质量投资开始进入
最优解；高预算下，Q 达到上界，之后新增预算重新主要流向规模。
这种结果体现了典型的“先规模、后质量、再规模扩展”的阶段性。质量成本占比在
中等预算达到较高水平，而高预算时虽然 Q=1，但质量成本占比反而下降，是因为一旦
质量拉满，新增算力只能继续用于 N、D 和注意力。

7.2.4 上下文长度与资源替代
注意力成本与基础训练成本的比值为 ηL_ctx/6，因此临界上下文长度只由 η 决定。
当 L_ctx 达到 6/η 时，两项成本相等。该解析结果提供了一个不依赖数值优化的判断标
准。
在题给参数下，临界值约 3×10^4，而 C7 最大上下文 32768 已略高于该值。这意味
着长上下文并不是可忽略的附加项，而可能改变最优资源结构。数值结果显示，随着 L
_ctx 增长，最优 N 降低而 Q 提高，体现“缩规模、提质量”的替代。
其直观原因是注意力成本与 N 成正比，长上下文会放大大模型的边际成本；而提高
Q 可以在不同比例上提升有效数据量。因此，当注意力变贵时，用质量替代一部分规模
成为更合理的选择。
7.2.5 参数不确定性传播
标度律参数来自有限数据拟合，因此最优配置本身也存在不确定性。若只报告单一
最优点，会给人一种参数完全确定的错觉。本文利用联合拟合参数协方差进行 Monte Ca
rlo 抽样，并对每组参数重新求解优化问题。
该做法把“模型参数误差”传播成“决策变量误差”。结果表明 N* 与 Q* 存在一定区间，
但中等预算阶段开始显著投资质量的定性结论保持稳定。换言之，具体最优点会移动，
但策略结构没有因参数扰动而改变。
这种不确定性传播比单独给参数标准误更贴近决策需求，因为最终使用者关心的是
“最优资源配置会不会因此改变”，而不是某个标度指数的小数点误差。
7.3 优化算法流程与收敛性讨论
问题三的数值求解可以概括为四个步骤。第一步，固定外生的算力预算与上下文长
度；第二步，在对数变量空间构造 N、D、Q 子问题，并使用多组初值运行 SLSQP；第
三步，独立求解配比 p 子问题；第四步，将两个子问题的最优值组合，计算总 Loss 与
各成本占比。
多起点策略的目的不是简单增加计算次数，而是检验非凸问题是否存在明显局部极
小。若不同随机起点最终都收敛到相近目标值和资源结构，则说明求解结果对初值不敏
感；若出现多个差异较大的可行解，则应报告最优值分布而不是只保留单点。
对数等式约束还可以改善收敛判据。原始 FLOPs 可能达到 10^24 量级，直接比较
约束残差容易造成浮点尺度问题；取对数后，约束转化为不同数量级上的相对偏差，更
适合数值优化器判断可行性。
配比优化采用 L-BFGS-B 与软支撑约束，是因为 p 子问题虽然不受算力限制，但存
在训练分布外风险。训练支撑越弱，二次模型越可能在边界给出虚假低损失，因此优化
过程必须把“统计可行”与“数学可行”区分开来。

构造情景。成本函数决定提高 Q 的边际价格；上下文长度决定注意力预算对规模的挤压；
标度律参数则决定不同资源的边际收益。

7.5 资源配置策略的阶段性解释
结合三档预算与连续预算扫描，可以把资源配置概括为三个阶段。第一阶段是规模
优先阶段，此时预算较低，任何额外质量处理都会显著挤压基础训练，因此 Q 保持基准
水平；第二阶段是质量进入阶段，规模边际收益下降后，部分预算转向数据质量；第三
阶段是质量饱和阶段，Q 达到上界，后续预算重新主要进入 N、D 和长上下文开销。
领域配比由于不进入预算约束，在三个阶段中都可以优先优化。因此更准确的决策
顺序是：首先在训练支撑内优化配比，其次根据预算阶段决定规模与质量的权衡，最后
再根据具体上下文长度调整 N 与 Q。
这种阶段性策略比单一的“Chinchilla 最优比例”更适合本题，因为它显式加入了质
量和注意力成本。当质量成本趋近于零时，模型会更愿意提高 Q；当注意力成本趋近于
零时，资源又更容易流向 N 与 D，经典规模规律可被视为广义模型的特殊情形。
7.6 问题三小结
问题三的核心贡献在于把问题二的损失规律转换为可执行的预算决策。利用 p 不进
入成本函数的结构，四维优化被严格分解；利用对数变量和多起点搜索，提高了跨数量
级数值求解的稳定性；利用结构断点、上下文敏感性和 Monte Carlo，把单点最优扩展
为阶段性资源策略。
最重要的结论并不是某一组 N*、D*、Q* 数字，而是资源配置会随预算发生结构变
化：低预算优先基础训练，中等预算开始显著投资质量，高预算使质量达到上界；长上
下文则会进一步推动“缩规模、提质量”的替代。

八、问题四建模与求解
8.0 从训练损失到能力前沿的建模思路
问题四与前三问最大的区别在于因变量从验证损失转为综合能力。Loss 是训练机制
层面的连续量，Benchmark 是能力表现层面的观测量，两者之间并不存在天然的一一对
应。因此，必须先分解历史能力增长，再建立桥接，最后才能把问题三的未来损失路径
转化为能力预测。
本文把问题四拆成三层：第一层用面板回归回答“历史增长来自哪里”；第二层用 Lo

8.1 能力度量与数据口径
8.1.1 综合能力指标的构造
六项 Benchmark 覆盖指令遵循、复杂推理、数学、科学问答、综合推理和高难知识
等不同能力维度。采用简单平均而非重新学习权重，一方面避免因样本量有限产生过拟

简单平均并不意味着六项能力同质。它只作为总体能力 Cap 的统一尺度，后续 C8

体平均需要结合结构信息解读。
开源筛选口径同时要求权重公开和许可证允许研究复现，目的是尽量保证样本之间

若不控制类型，可能把后训练收益错误归因于参数规模。
8.1.2 缺失数据与样本选择偏差
部分模型缺少训练 token 数 D，只能通过 C≈6ND 和计算量字段反推。这会引入测
量误差，因此面板回归中 D 项不显著不能简单解释为“数据量无效”，更可能反映变量质
量不足。
另一个偏差来自只选每月最强模型。如果前沿模型中 chat、微调或小型高效模型比
例不断变化，时间趋势会与模型类型混淆。本文因此使用满足开源口径的全量 424 个模
型，并在回归中显式控制 chat 和后训练因素。
综合能力 Cap 取 IFEval、BBH、MATH Lvl 5、GPQA、MUSR 与 MMLU-PRO 六项
Benchmark 的简单平均。开源模型以“权重公开且许可证允许研究复现”为筛选标准，并
按 pretrained 与 chat 两类分别标记。时间轴使用模型提交日期；对于缺失的训练数据量
D，结合 C≈6ND 与 C4 中的计算量信息进行反推。
为了避免仅选择每月前沿模型造成样本选择偏差，规模与技术进步的分解使用满足
开源口径的全量模型。最终可用于面板回归的样本数为 424。
8.2 规模扩张与非规模技术进步分解
8.2.1 面板回归的识别逻辑
回归中的 b_N 描述在控制时间、类型和其他变量后，参数规模与能力之间的条件相
关关系；b_t 则吸收随时间发生、但没有被 N、D、chat、ft 明确解释的系统性进步。这
个时间项可理解为架构、优化器、数据工程、训练策略等非规模因素的综合代理。
同一组织或模型族的多个版本往往共享架构、数据和训练代码，因此误差项并不独
立。若使用普通标准误，会低估参数不确定性。按组织聚类标准误能够允许组内相关，
使显著性判断更稳健。
b_N 显著为正表明规模本身确实有效；但增长核算显示样本期内典型 N 没有持续扩
张，所以历史能力上升并不是由“参数不断变大”驱动。这一区分避免了把“规模有效”与
“历史增长由规模贡献”混为一谈。
8.2.2 增长贡献的解释边界
非规模贡献约 100.5% 是基于样本期首尾典型水平和回归系数进行的增长核算。由
于数据量 D 存在反推误差、时间趋势并非外生冲击，因此这一比例更适合被理解为统计
分解，而不是严格的因果效应。

贡献比例略超过 100% 并不矛盾，因为某些规模变量在样本期可能出现轻微下降，

lnCap=b₀+b_N lnN+b_D lnD+b_t t+b_chat chat+b_ft ft+ε （16）
同一组织或模型族内的观测并非独立，因此标准误按组织聚类。估计结果为 n=424、
R²=0.442，其中 b_N=0.350（SE=0.028，t=12.4），参数规模效应高度显著；b_t=1.05（t

有下降，因此规模扩张的净贡献约为 0%，非规模技术进步贡献约为 100.5%。这一结果
并不意味着“规模无效”，而是说明规模弹性虽然显著为正，但样本期内开源生态并未依
靠持续放大模型规模来获得主要能力提升；实际增长更多来自架构改进、数据工程、训
练策略与后训练技术。
8.3 Loss–Benchmark 桥接模型
8.3.1 为什么直接桥接会失败
不同模型报告的验证损失往往使用不同数据集、不同 tokenization 或不同训练阶
段，直接把所有 Loss 与 Benchmark 放在同一回归中，会受到严重的口径混杂。C6 中只
有少数 Pythia 样本具有较高可比性，这也是简单指数桥接出现负 R² 的主要原因。
因此，桥接模型不能只依赖 Loss，而需要加入时间与模型类型控制项，并对高可比
样本赋予更大权重。这样做不是认为高可比样本“绝对正确”，而是承认它们在 Loss 口
径上更接近同一测量体系。
Cap_max 采用开源榜单高分位锚定，使桥接函数具有饱和上界，避免 Loss 继续下
降时能力被无限指数放大。λ 则控制 Loss 改善转换为能力提升的速度。
8.3.2 桥接模型的不确定性处理
λ 的置信区间较宽，反映桥接样本稀缺与口径混杂。若未来直接把 λ 的点估计用于
长期预测，误差会被指数放大。因此本文在预测阶段通过 bootstrap 传播桥接参数不确定
性，使最终能力区间能够反映这一来源。
时间协变量 β_t 在桥接中主要用于控制样本构成变化，而不是再次估计技术增长。
若同时把 β_t 当成未来技术趋势外推，会与面板回归和时序模型重复计入时间效应。因
此本文将其限定为混淆控制项。
C6 中共有 75 条同时具有验证损失与 6 维 Benchmark 得分的观测，其中 7 条 Pythia
样本具有较高可比性，其余样本使用的验证集并不完全一致。若直接用 Cap=K·exp[−λ(L
−E)] 做回归，全样本水平 R² 为 −0.163，说明时间和模型类型造成了明显混淆。为此，
本文将饱和能力锚定在开源榜单 95% 分位，并引入时间与模型类型协变量：
Cap=Capₘₐₓ·exp[−λ(L−E)]·exp(β_t t)·exp(β_chat chat) （17）
令高可比样本权重为其他样本的 3 倍，拟合得到 λ=1.489，95% CI 为 [1.117,1.925]，
总体方向稳定，即损失越低，能力越高。修正后水平 R² 提升至 0.187。由于 β_t 受到桥
接样本构成变化影响，外推时将其作为混淆控制项而非技术增长项，并在后续 bootstrap
中传播桥接参数不确定性。

8.6 预测结果的稳健性与解释
问题四的预测存在三类主要不确定性。第一类来自未来算力增长情景，本题采用年
化 1.5 倍作为放缓设定；第二类来自 Loss–Benchmark 桥接参数，尤其是 λ 的估计区间；
第三类来自 Benchmark 口径随时间变化以及不同模型族之间的不可比性。
机制路径对算力假设最敏感，但其优点是能够显式反映资源配置变化；月度路径对
近期技术波动最敏感，但能够及时吸收新模型突破；年度路径对长期趋势最敏感，同时
最容易受到评测体系变化影响。三条路径相互补充，能够避免把某一种不确定性误认为
确定趋势。
逆方差融合不是简单平均。若某条路径的历史残差更大、参数区间更宽，其方差就
更高，在最终预测中的权重更低。这样可以用数据自动调整不同预测来源的重要性，而
不是人为认为机制模型或时间序列模型一定更可信。
12 个月与 24 个月预测的置信区间明显扩大，符合长期预测不确定性累积的规律。
论文因此把 49.1 和 51.9 作为条件情景下的中心预测，而不是确定性的性能承诺。

模型评价不仅比较拟合优度，还要检查数据口径、外推范围、参数可解释性与决策
稳定性。本文四个问题使用的数据来源复杂，如果只报告 R² 容易忽略半合成数据、估

因此评价体系主要从四个维度展开：一是拟合与检验表现；二是跨数据源和跨尺度
的一致性；三是参数扰动下结论是否稳定；四是模型结论能否被解释为可执行的资源决
策。
9.1 模型优势
1、建模链条具有闭环性。问题一的 Q 与 φ(p) 并非停留在描述统计，而是在问题二
和问题三中继续发挥作用；问题三的 Loss 又被问题四的桥接模型转换为能力。参数与
结论沿同一主线传递，减少了不同问题间的口径断裂。
2、图表与论证目标一一对应。质量评分图用于验证域间差异，冲突率图用于揭示
结构异常，跨尺度图用于检验配比可迁移性，成本占比与最优质量图用于识别结构性转
移，能力前沿图则用于呈现多路径预测不确定性。图表不是装饰，而是承担具体证据功
能。
3、结果解释强调条件性。对于 ΔL=0.526、质量等效参数扩大 14.2%、结构断点 log
C≈21 等结论，论文都限定在当前数据与成本参数条件下，避免把局部经验结果误写成
普适规律。
4、跨来源统一性强。本文没有将真实数据与半合成数据分别孤立拟合，而是通过
共享幂指数与来源固定效应构造统一模型。δ=0.073 且两个来源 R² 均高于 0.94，说明
“共享形状、允许水平差”的假设得到了数据支持，同时避免了半合成数据单独拟合时不
可约损失明显偏低的病态结果。
5、四个问题之间具有明确的数据传递关系。问题一给出 Q 与 φ(p)，问题二将二者
纳入广义标度律，问题三在同一损失函数上进行资源优化，问题四再通过 Loss–Benchm
ark 桥接将损失转换为能力，形成从数据质量到能力前沿的闭环，而不是四个相互独立
的局部模型。
6、检验方式与问题结构相匹配。领域配比跨尺度检验采用配方差分相关，避免绝
对损失水平被模型规模支配；技术进步分解使用全量面板并按组织聚类标准误，降低只
选前沿模型造成的样本选择偏差；优化部分采用对数变量和多起点搜索，改善跨数量级
变量带来的数值稳定性。
7、重视不确定性与外推边界。对于 A12–A15、B8、C6 等存在口径或可比性问题
的数据，不强行作为独立验证，而是明确区分定量检验与定性参照；同时利用 Monte Ca
rlo 与 bootstrap 将参数误差传播到最优配置和前沿预测区间，使结论更加稳健。
9.2 模型不足
1、配比模型参数较多。二次项和交互项提高了拟合能力，但也增加了过拟合风险。
虽然跨尺度差分检验和训练支撑约束降低了该风险，未来仍可考虑稀疏正则、贝叶斯收
缩或低秩交互结构。
2、质量评分仍是代理指标。22 个质量信号覆盖了多种文本特征，但并不直接等价
于“对下游能力的真实训练价值”。未来若获得同一语料子集在多模型上的训练增益，可
使用监督学习重新校准 Q，使其从统计质量进一步接近效用质量。
3、优化成本函数依赖题设形式。质量成本和注意力成本的具体参数若发生变化，
最优 Q 与结构断点也会改变。因此问题三更重要的输出是资源配置规律与求解框架，而
不是某一组固定数值。

4、未来能力预测受评测体系变化影响。Benchmark 会随时间发生饱和、污染或版
本更换，长期前沿预测需要持续更新桥接样本与任务集合，不能把当前映射永久固定。
5、配比模型的大尺度外推仍缺乏直接实测支撑。A12–A15 与本文配比效应方向相
反，但其生成口径不明，因此只能说明 10B、70B 区间的不确定性较大，尚不能判断哪
种方向更接近真实训练。
6、数据质量指数 γ 的识别仍较依赖半合成实验。B8 存在基线漂移和噪声放大，无
法作为高质量独立验证，因此 Q 对损失的定量影响还需更多真实训练实验进一步校准。
7、能力桥接样本较少且评测口径混杂。C6 中高可比样本仅 7 条，导致 λ 的置信区
间偏宽；面板回归中的 D 又多由 C≈6ND 反推，使数据量效应的识别能力有限。因此问
题四的贡献分解更接近结构化统计解释，而非严格的因果识别。
8、综合质量评分对赋权方法仍存在中等敏感性。熵权法与 CRITIC 的样本级 Q 相
关为 0.564，虽不影响域级排序，但对单篇文本的相对位置可能产生影响。未来可引入
监督信号或层次贝叶斯方法提高质量评分的稳定性。
9.3 模型推广
在大模型训练规划中，该框架可形成“先配比、再规模、后质量敏感性”的决策流程：
先在既定 token 预算下优化领域结构，再根据算力水平决定 N 与 D，最后比较质量提升
的边际收益与成本。对于长上下文模型，还应把注意力预算单独列出，避免只使用 6ND
低估总成本。
在多模态训练中，文本、图像、音频和代码的比例同样属于成分数据，可借鉴 clr
变换和配比差分检验；在课程学习或多任务训练中，不同任务采样率也可以被视为资源
配比变量。
在技术演进研究中，面板增长核算与多路径预测方法可迁移到芯片性能、自动驾驶、
机器人等领域。只要能够构造规模变量、时间变量与能力指标，就可以区分“规模投入”
与“非规模技术进步”的相对作用。
9.4 综合结论
本文围绕算力约束下的大语言模型资源配置问题，依次完成数据质量评价、领域配
比建模、广义标度律构建、资源联合优化和能力前沿预测。与传统只研究 N 与 D 的标
度律不同，本文把数据质量 Q 和领域结构 p 显式纳入，从而能够讨论“规模、数据、质
量、配比”之间的统一权衡。
问题一表明，不同领域的数据质量存在显著差异，且部分质量指标会受到长文档效
应影响。通过 ECDF、熵权法、冲突消解和成分数据建模，可以得到稳定的 Q 与 φ(p)，
为后续统一建模提供数据基础。
问题二表明，质量可以通过有效数据量 D·Q^γ 被纳入经典幂律结构，真实轨迹与半
合成质量实验在共享幂指数、允许有限水平偏移的条件下可以联合解释。质量提高 0.1
在参考点附近具有与扩大参数和增加数据同量级的收益，说明数据质量不是次要因素。
问题三表明，领域配比优化由于不额外消耗 FLOPs，可以与 N-D-Q 优化分离；最
优资源结构会随预算出现阶段性变化，并在长上下文条件下进一步向高质量数据倾斜。
结构性转移比单一最优点更能反映资源决策规律。
问题四表明，规模本身仍显著影响能力，但样本期内开源生态的能力提升更多来自
非规模技术进步。多路径预测给出未来能力中心趋势及不确定区间，逐任务分析又揭示
不同能力维度的非同步演进。
9.5 对实际大模型训练的建议

第一，在预算确定之前，应先审查数据结构。若领域配比明显偏离有效配方，即使
继续扩大参数和 token，也可能无法充分利用已有算力。配比调整通常不增加总 token 数，
是优先级较高的结构优化手段。
第二，在低预算阶段不宜过早追求极高质量数据。质量清洗和高质量数据获取本身
具有成本，若基础训练规模不足，过多预算用于质量可能得不偿失。随着预算提高和规
模边际收益下降，再逐步增加质量投入更合理。
第三，长上下文模型必须单独核算注意力成本。上下文达到数万 token 后，注意力
开销可能与基础训练同量级，此时继续扩大参数的机会成本明显增加，应重新评估规模
与质量的最优组合。
第四，能力预测不能仅依赖历史趋势。若未来算力增速、Benchmark 体系或后训练
方法发生变化，单一时间序列外推容易失真。更稳妥的方式是同时使用机制模型、近期
趋势和长期参照，并持续更新桥接关系。
第五，所有最优数值都应结合数据支持范围解释。配比收益、质量等效规模和结构
断点均依赖当前附件数据与成本函数。实际部署时应重新使用目标模型、目标数据和目
标硬件进行校准，而不是机械套用本文数值。
9.6 论文整体创新点概括
本文的第一项特点是把数据质量和领域配比同时纳入标度律资源配置框架，使数据
的“质量”和“结构”不再只是前处理因素，而成为可优化变量。
第二项特点是利用来源固定效应实现真实训练轨迹与半合成质量实验的统一拟合，
并通过多层验证区分真实验证、半合成检查和外推讨论，明确不同证据的可信层级。
第三项特点是识别出联合优化的可分离结构，并进一步通过连续预算扫描定义和定
位资源配置的结构性转移，使结果从三个离散预算点上升为阶段性决策规律。
第四项特点是将资源优化与能力前沿预测连通。问题三给出未来 Loss，问题四通过
桥接和多路径融合将其转化为 Benchmark 能力，使整篇论文形成从原始数据到最终能力
决策的闭环。
本文的质量折算标度律可用于“购买更多数据、提高数据质量还是扩展模型规模”的
统一比较；成分数据与差分检验框架可迁移到多任务训练、课程采样或多模态数据配比
问题；可分离优化结论适用于任何存在“某些决策变量影响目标函数但不进入预算约束”
的资源配置场景；面板增长核算与多路径预测方法也可推广至芯片、机器人和自动驾驶
等技术演进研究。
