# TASK-Q01B：质量缺失处理策略裁决

裁决日期：2026-09-24。状态：**方法裁决完成，尚未实施。**

本裁决只使用已验收的TASK-Q01A及R1证据，不重新读取A1–A3，不计算新的数值Q或质量组得分，不修改质量代码。原TASK-Q01A正式运行继续保留`PARTIAL`和退出码2。

## 证据基础

- all_unique共261086条，11个主Q特征完整261067条，缺失19条，缺失率0.0072772956%。25特征完整数也为261067。
- 缺失只涉及modernbert_professionalism 6条和modernbert_reasoning 13条，两者不重叠。19条均仍有2个有效质量组；没有0组或1组有效案例。
- 按域：wikipedia 14/10000（0.14%）、commoncrawl 4/9640（0.0414937759%）、github 1/203752（0.0004907927%）。
- 按角色：A1_calibration 13/40943（0.0317514593%）、A1_holdout 5/10287（0.0486050355%）、extension_new 1/209856（0.0004765172%）、extension_overlap 0。
- 缺失来源是原始六元素logits列表含NaN后，现有提取逻辑使对应标量失效。现有证据没有证明缺失机制为MCAR、MAR或MNAR。

## 方案比较

|方案|优点|主要问题|裁决|
|---|---|---|---|
|静默填0|可得到全覆盖数值|0具有质量含义，会把技术性缺失误写成最低质量并引入域偏差|否决|
|从底层数据删除19条|实现简单|破坏物理记录完整性和审计链；后续非Q分析也会无谓丢失信息|否决|
|按剩余2组重新等权计算Q|保留19条Q|同一Q在不同记录上使用不同组权重，损害横向可比性；把缺失组隐式重分配给其余组|不作主方案|
|全局或域内均值/中位数单次插补|保持固定11特征公式并获得全覆盖Q|插补值不是观测值；若使用holdout或扩展数据估计会泄漏验证信息；主结论会依赖未验证假设|只用于预先规定的敏感性分析|
|回归、多重插补或缺失指示模型|可表达条件关系或插补不确定性|仅19条且只缺两个特征，复杂度和模型假设远大于可获得信息；缺失机制未识别|当前否决|
|主Q严格完整案例，底层记录保留|所有数值Q都使用同一11特征、三组及权重；不引入虚构值；损失仅19条|19条没有主Q，域汇总必须显式报告覆盖率，wikipedia需特别披露|采纳为主方案|

## 最终决定

1. **主分析采用11个主Q特征的严格完整案例口径。** 只有11个特征均有限时才生成数值Q。主Q有效样本为261067，19条保持`Q=NaN`和`Q_valid=False`，不把它们物理删除，也不从其他不依赖Q的诊断或统计中删除。
2. **所有Q相关汇总同时报告`n_total`、`n_Q_valid`、`n_Q_missing`和coverage。** 均值、标准差、分位数及区间只使用`Q_valid=True`记录；标准差明确有效n与`n-1`方差除数。不得再把总行数写成Q统计的有效分母。
3. **三个质量组仍按固定构成和三组等权定义。** 不因某组缺失而把其权重重分配给另外两组。分歧range和ddof=0组间std可按现有skipna语义在两个有效组上计算，但必须随附`n_groups_valid`；它们不能代替缺失的主Q。
4. **不填0，不用holdout或extension估计插补值，不重新拟合归一化参数。** 缺失特征、原始异常原因、域、角色和行身份必须保留。
5. **后续实施时增加一项敏感性分析，不改变主结果。** 仅用A1 calibration中同域、同特征的有效记录计算归一化尺度上的中位数；固定后应用于calibration、holdout和extension。A3 github的敏感性值使用A1 calibration/github，不使用A3自身。比较完整案例与该插补方案的域均值、域排序及关键下游结论，并清楚标记为敏感性结果。

## 决定依据与风险控制

完整案例损失占all_unique的0.0072772956%。在Q被限制于[0,1]的前提下，任意补齐19条对全体均值相对完整案例均值的绝对影响上界为19/261086，即0.0000727730；域内相应上界为wikipedia 0.0014、commoncrawl 0.0004149378、github 0.0000049079。该界限只说明均值的最大机械影响，不证明缺失随机，也不替代后续敏感性分析。

选择完整案例作为主方案的核心理由是保持每个数值Q的定义一致。敏感性分析用于检查缺失集中在wikipedia等域时是否影响域级结论；它不把插补值升级为观测值，也不用于重新选择主策略。
