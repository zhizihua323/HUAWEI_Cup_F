## 3. 模型形式

**主拟合（L(N,D)）**

```
L = E + A·N_B^{-α} + B·D_B^{-β}
```

- 五个参数在对数空间优化以保证正性；每次拟合 12 个多起点；边界 `E,A,B ∈ [1e-6,100]`（E 上界 10）、`α,β ∈ [0.005,3]`。
- 损失函数候选：普通最小二乘 / soft-L1（尺度 0.10）；权重模式候选：原始检查点等权 / 每个模型十个 log D 区间等权。
- 所有早期训练点保留（不做“只留收敛点”的筛选）。

**质量情景（Q 通道，当前未验证）**

```
L = E + A·N_B^{-α} + B·[D_B·exp(k(Q − Q_ref))]^{-β}
```

`k>0` 表示提升 Q 降低损失；`Q_ref` 固定为 0.5（情景锚点）；k 在 log 变换后于 [−20, 20] 内自由估计。**Q 的“等效 token”解释是情景公式的性质，不是已证实的现实替代率。**

**边际效用（由上式解析得到，供问三使用）**

令 `X = A·N_B^{-α}`、`Y = B·[D_B·exp(k(Q−Q_ref))]^{-β}`，则
`∂L/∂N_B = −αX/N_B`、`∂L/∂D_B = −βY/D_B`、`∂L/∂Q = −βkY`；
对应损失弹性为 `−αX/L`、`−βY/L`、`−βkQY/L`。换算到物理 N、D 需除以 10⁹。

## 7. 哪些只是探索结果

- **整轮是探索性基线**（报告首行自述：可复现的探索性基线，不是定稿模型）：配置比较、1% 简单性偏好、权重模式都是分析选择。
- **B1 参数值**：建立在近乎确定性拟合上，且选型由验证分数指导、无独立最终测试集；参数可作为后续建模的**起点**，不是已确认的自然常数。
- **外部对照 B2/B3/B4/B5/B10**：单套参数的迁移比较，属探索；B3 是插值、B10 是估算，都不能升级为验证。
- **质量拟合 B6/B7**：同源半合成数据；B7 新增 90 点的插值检验（RMSE 0.0491）也是同源检验。
- **B6 内部外推**：训练 Q≤0.6 预测 Q>0.6 时 RMSE 0.0956、偏差 +0.0394（同时放大误差与正偏），说明 Q 方向外推不可靠。
- **迁移情景与替代率推导**：`X_new = X − Y[1 − exp(−βkδ)]`、`N_new = N_B(X/X_new)^{1/α}` 等只是该情景公式的解析推论，不是经验替代率。
- **B9/B11** 是元数据覆盖检查，不是模型结果。

## 10. 后续进入广义模型 L(N,D,Q,p) 时可复用的接口

**可直接复用的对象**

1. **参数对象**：`{E, A, B, alpha, beta}`（+ 情景 `{k, Q_ref}`），附带 `units`、`observed_ranges`、`quality_scenario_status`、`not_included`、`limitations` —— 这是交给广义模型的标准交接格式（`scaling_params.json`）。
2. **预测函数**：`predict(params, N_B, D_B, Q=None)` → 标量 Loss；Q 通过 `D_eff = D_B·exp(k(Q−Q_ref))` 进入。**广义模型的 p 方向应以同样方式乘进有效 token 或损失水平项。**
3. **拟合/验证工具**：`fit_model(df, loss, weight_mode, nstarts)` + 两类结构化划分（按 N 留一、按 D 末 20% 时间外）。广义模型应沿用“按模型/规模分组、不随机拆行”的验证原则。
4. **边际效用接口**：`∂L/∂N`、`∂L/∂D`、`∂L/∂Q` 及弹性公式（§3），可直接作为问三的梯度/影子价格输入；注意物理单位换算 ×10⁻⁹。
5. **质量替代情景**：`N_new = N_B·(X/X_new)^{1/α}`（仅当 `X_new>0`）——作为敏感性情景保留，不写实数结论。
6. **证据分层标签**：`data_nature ∈ {observed, semisynthetic, interpolated, published_observed, estimated, metadata}` 与 `split_role`，可直接作为广义模型的数据分层键。

**接入广义模型前必须补齐**

- (i) **p 通道**：把配比模块的 `f(p) → 13 维 Loss` 与 N/D/Q 项在同一目标函数内衔接（当前两条链独立）；
- (ii) **Q 标定**：A 域质量评分 → B `Q_score` 的映射，并给出映射不确定性；
- (iii) **来源标定**：B1 与半合成/文献材料之间显式引入偏移/尺度参数（B2 的恒定偏差即为证据）；
- (iv) **冲突处置**：B8 方向冲突须有明确规则（分层参数或排除），不能静默合并；
- (v) **外推标记与边界**：保留 `observed_ranges` 与“超出即外推”的强制标记；
- (vi) **独立测试集**：目前不存在，进入论文强结论前必须补足或明确降级为情景。

**登记表口径**：`evidence/baseline_result_registry.csv` 每行一条可引用事实，字段为 `result_id, module, item, config_or_model, dataset, data_nature, split_role, n, metric, value, unit, artifact, source_table, verification, verification_method, claim_level, caveat, interface`；`verification` 取 `V1_本轮复算 / V2_恢复轮核验 / V3_仅落盘记录 / V4_不可复算_需重拟合`，`claim_level` 取 `A_可用_附边界 / B_探索性 / C_仅内部参考 / D_禁止用于论文结论`。
